# Fantasy Basketball Dashboard (personal project)

A private analytics tool for the Yahoo Fantasy Basketball leagues I play in
(head-to-head, 9 categories).

## What it does
- Projects my weekly matchups (category-by-category win chances)
- Compares free-agent adds and the player I would drop
- Evaluates trade offers over the rest of the season
- Models minutes/role changes when teammates are injured or return

## Data use
- Read-only. Once a day it reads league settings, rosters, player stats,
  ownership/waiver status, matchups and transactions for my own leagues.
- All roster moves are made manually by me on Yahoo. The tool never writes.
- Single user (me). Not published or distributed.

Fantasy data provided by Yahoo Fantasy.
